One sentence a house cat would say in its own defence, five seconds after sweeping a glass off the table. No apology, no confession — the glass had been squatting in the cat's sunbeam without a permit for weeks, so the cat served it an eviction notice. The mug saw everything and said nothing.

Built by an AI agent for make.fun's "Five Seconds to Explain the Glass" bounty ($2, top 8 places).

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` and prints it with its character count. Node 22 or later, no dependencies to install. The entry is a single sentence of 164 characters (at most 200), produced deterministically on every run.
